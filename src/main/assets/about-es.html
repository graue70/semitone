Semitono es un programa libre de código abierto. Es un fork mantenido del Semitono original de Andy Tockman (código fuente). El código fuente de este fork está disponible en GitHub bajo el GPLv3.

Si tienes algún comentario o algunas sugerencias para mejorar Semitono, por favor abre un issue en GitHub.

Este programa utiliza:

  • bibliotecas desde el proyecto FFmpeg, bajo el GPLv2 o posterior
  • iconos de Material Design y la biblioteca Oboe, ambos licenciados por Google bajo el Apache 2.0
  • audio proporcionado por el proyecto University of Iowa Musical Instrument Samples
