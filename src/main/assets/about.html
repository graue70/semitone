Semitone is free, open-source software. It is a maintained fork of the original Semitone by Andy Tockman (source code). The source code of this fork is available on GitHub under the GPLv3.

If you have any feedback or suggestions as to how to improve Semitone, please open an issue on GitHub.

This software uses:

  • libraries from the FFmpeg project, under the GPLv2 or later
  • Material Design icons and the Oboe library, both licensed by Google under the Apache 2.0
  • audio provided by the University of Iowa Musical Instrument Samples project
